GAMES FAD — versão corrigida

Nesta versão, a forma de adicionar jogos voltou ao modelo original:
você adiciona um novo <div class="card"> diretamente no HTML.

Não há:
- formulário de adicionar jogo no site;
- cadastro de imagens;
- lista de fotos;
- localStorage para jogos.

O script.js somente:
- lê a nota de cada card;
- ordena os cards da maior para a menor nota;
- mantém a ordem original quando as notas são iguais;
- renumera automaticamente os jogos.

Para adicionar um jogo, copie um card existente no 2026.html ou Ranking.html,
troque a imagem, nome, plataforma e nota. A organização/numeração será feita
automaticamente ao abrir a página.

Observação: as imagens continuam sendo referenciadas pela pasta Games,
por exemplo: Games/Modern_Warfare_3.jpg.
